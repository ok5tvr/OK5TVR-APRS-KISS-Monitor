Společné nastavení

Bez SSID. Stejná značka slouží k přihlášení a označuje web i displej Raspberry.

SSID 0 znamená značku bez přípony.

Zelená = aktivní režim · červená = vypnutý režim. Přepnutí ukončí předchozí funkci; RF server a jednotlivé přenosy se povolují v příslušné sekci.
