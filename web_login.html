OK5TVR / APRS

Přihlášení do webové konzole

Stejné prostředí pro Raspberry Pi a Windows. Přístupový token vygeneroval program při prvním spuštění.

Údaje najdeš v souboru ~/.config/ok5tvr-aprs/secrets.json (Windows: %USERPROFILE%\.config\ok5tvr-aprs\secrets.json). Používej pouze důvěryhodnou LAN nebo zabezpečenou VPN; HTTP není šifrované.
